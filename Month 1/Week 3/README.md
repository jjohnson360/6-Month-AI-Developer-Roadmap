# CLI Calculator

A simple, robust command-line calculator built in Python as part of Month 1, Week 3 of the 6-month development roadmap.

## Features
* Basic arithmetic operations (Addition, Subtraction, Multiplication, Division, Exponentiation).
* Robust input validation for non-numeric entries.
* Division-by-zero error handling.

## Usage
Run the script interactively:
```bash
python calculator.py
