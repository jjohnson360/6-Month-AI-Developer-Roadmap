# Browser Password Generator

A responsive, client-side password generator built with HTML, Tailwind CSS, and vanilla JavaScript as part of Month 1, Week 4 of the development roadmap[cite: 1].

## Features
* Adjustable password length slider (4 to 32 characters).
* Dynamic toggles for numeric and special symbol inclusion.
* One-click clipboard copying using the browser Clipboard API.
* Deployed live via GitHub Pages.

## Usage
Simply open the live URL or open `index.html` in any modern web browser.
