# Browser Password Generator

A responsive, client-side password generator built with HTML, Tailwind CSS, and vanilla JavaScript as part of Month 1, Week 4 of the development roadmap.

## 🌐 Live Demo
Access the live application here: **[https://jjohnson360.github.io/6-Month-AI-Developer-Roadmap/](https://jjohnson360.github.io/6-Month-AI-Developer-Roadmap/)**

## Features
* Adjustable password length slider (4 to 32 characters).
* Dynamic toggles for numeric and special symbol inclusion.
* One-click clipboard copying using the browser Clipboard API.
* Deployed live via GitHub Pages.

## Usage
Simply visit the [Live Demo](https://jjohnson360.github.io/6-Month-AI-Developer-Roadmap/) or open `index.html` in any modern web browser.
